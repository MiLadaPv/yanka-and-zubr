# Янка і Зубр

A Belarusian folk platformer. Yanka runs the old road, and a young European bison named Zubr runs it with her. Six embroidered suns have blown off Grandmother's rushnik. The way home crosses the primeval forest, the Polesie marshes, the Nyoman, the flax fields, Lake Narach, and Kupalle night.

## Play

```bash
npm start
```

Open http://localhost:4173

Arrows or A and D run. Space or W jumps. E or J tells Zubr to ram. Stomp enemies from above. Hedgehogs are all needles, so ram those. Draniki heal, kvass hurries, linden honey takes one hit, and khaladnik clears marsh fog.

The game keeps progress in this browser.

## The road

Belavezhskaya Pushcha, Polesie, the Nyoman and Mir, flax and Dazhynki, Lake Narach, and Kupalle. The table has draniki, kvass, rye bread, syrniki, and cold khaladnik. The woods have the zubr, the stork, the beaver, and the old spirits: Vodyanoy, Tsmok, Palyavik, Rusalka, and Lesun.
